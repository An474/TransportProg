# Информационная система транспортного отдела

Единая автоматизированная веб-система для транспортного отдела, заменяющая разрозненные Excel-таблицы. Разработана на основе предоставленного ТЗ и реального парка автомобилей (217+ ТС, 124+ водителей, история штрафов, путевых листов и ремонтов).

---

## 🚀 1. Быстрый локальный запуск (Windows)

Программа полностью настроена для работы на локальном компьютере:

1. Запустите файл **`start_local.bat`** (двойным кликом).
2. Скрипт проверит окружение, запустит сервер и **автоматически откроет веб-интерфейс в браузере**:
   - **Локальный адрес:** `http://localhost:8000`
   - **Документация API (Swagger):** `http://localhost:8000/docs`

---

## 👥 2. Одновременная работа сотрудников в сети (3–10+ пользователей)

Для одновременной работы коллег из транспортного отдела:
1. Запустите систему на основном компьютере отдела через `start_local.bat`.
2. Консоль при запуске покажет сетевой адрес вашего компьютера в офисной сети:
   ```text
   Ссылка для коллег отдела в локальной сети: http://192.168.x.x:8000
   ```
3. Остальные сотрудники просто открывают эту ссылку в своем браузере (Chrome, Edge, Яндекс).
4. **Никакого дополнительного ПО на компьютеры других сотрудников устанавливать не требуется!**

---

## 🔐 3. Учетные записи для входа

В системе предустановлены три роли с разграничением прав доступа:

| Роль | Логин | Пароль | Права |
|---|---|---|---|
| **Администратор** | `admin` | `admin123` | Полный доступ: управление пользователями, просмотр журнала аудита, резервное копирование |
| **Диспетчер** | `dispatcher` | `disp123` | Операционная работа: добавление и редактирование ТС, водителей, пересадок, путевых листов, штрафов и ТО |
| **Руководитель** | `viewer` | `view123` | Просмотр данных, аналитика дашборда и выгрузка отчетов (без права случайного изменения данных) |

## 📋 4. Основные разделы и возможности системы

### 1. Дашборд руководителя и диспетчера
- Сводные показатели автопарка в реальном времени (Всего ТС, В строю, В ремонте, В резерве).
- Срочные виджеты внимания: автомобили с истекающим или просроченным техосмотром и страховкой.
- Реестр неоплаченных штрафов с быстрым переходом.

### 2. Автопарк (Реестр и Карточка ТС)
- Полный учет всех 217+ автомобилей компании (Meganet, EPB, NLS, CCK).
- **Цветовой светофор сроков:**
  - 🟢 **Зеленый:** срок страховки/техосмотра в норме (>30 дней).
  - 🟡 **Желтый:** осталось менее 30 дней (требуется записаться).
  - 🔴 **Красный:** срок истек (просрочено, выезд запрещен).
- **Карточка автомобиля:** все связанные данные в одном окне (общие реквизиты, текущий водитель, история всех пересадок, история штрафов и ремонтов).

### 3. Водители и бригады
- Единая база водителей, бригадиров, сварщиков ВОЛС, техников ОИС и монтажников.
- Корректная поддержка казахского алфавита (Қ, Ң, Ғ, Ү, Ұ, Ә, Ө, І) в именах.
- Привязка к закрепленному автомобилю и отслеживание статуса (работает, отпуск, больничный, уволен).

### 4. Журнал пересадок и замен
- Решение главной проблемы Excel: исключение путаницы при временной передаче машин.
- В 2 клика фиксируется: автомобиль → предыдущий водитель → новый водитель → даты и причина передачи («Отпуск», «Ремонт», «Замена»).
- При создании пересадки система автоматически связывает ее с путевыми листами и штрафами.

### 5. Путевые листы и контроль пробега
- Формирование путевых листов с автоподтягиванием спидометра выезда и закрепленного водителя.
- Еженедельный контроль возврата маршрутных листов (1, 2, 3, 4 недели) прямо в таблице.
- Фиксация утерь путевых листов с возможностью выдачи дубликата.

### 6. Штрафы ПДД и Служебные записки
- Реестр штрафов с контролем дат: *Поступил из бухгалтерии → Оповещен водитель → Оплачен в Kaspi*.
- **Умное автоопределение водителя:** при внесении штрафа система по дате нарушения и автомобилю автоматически проверяет журнал пересадок и путевых листов и находит ответственного водителя.
- **Генератор служебной записки в СБ:** автоматическое формирование готового документа в Excel со списком сотрудников, отказавшихся добровольно оплачивать штрафы.

### 7. ТО, Ремонты и Эвакуация
- Учет планового ТО по пробегу, замен масла, геометрии и лобовых стекол.
- Учет эвакуаций (ИП Мухраев, номера ЕРП).
- Учет кузовных дефектов и простоев в ремонте (с автоматическим изменением статуса авто на `В ремонте` и возвратом в `В строю` по окончании работ).

### 8. Учет ГСМ и Топливных карт
- Нормативы расхода на 100 км по моделям.
- Ввод фактических заправок по номерам топливных карт.
- Автоматический расчет нормативного расхода по пробегу и отклонений (экономия / перерасход).

### 9. Отчеты и Экспорт в Excel
- Выгрузка актуального реестра автопарка в нативный Excel (`.xlsx`) со светофором и форматированием.
- Выгрузка служебной записки по задолженностям в Службу безопасности.
- Аналитические срезы по компаниям, видам топлива и подразделениям.

### 10. Журнал аудита
- Непрерывная фиксация всех действий (кто, когда, какое поле изменил с детализацией «Было → Стало»).
- Полная защита от несанкционированного удаления данных.

### 11. Резервное копирование
- Встроенный фоновый планировщик создает zip-копию базы данных каждую ночь в 00:00 в папку `./backend/data/backups/`.
- Кнопка ручного создания резервной копии «в 1 клик» в панели администратора.

### 12. Пользователи и разграничение прав (Только Администратор)
- Создание новых учетных записей сотрудников (логин, пароль, ФИО, роль).
- Редактирование прав доступа (Администратор, Диспетчер, Руководитель/Просмотр).
- Блокировка и разблокировка доступа в 1 клик.
- Смена паролей сотрудникам при утере.
- Удаление неактивных пользователей с защитой от удаления собственного аккаунта.

## ☁️ 5. Развертывание на сервере / в облаке (в будущем)

Приложение спроектировано по стандарту **Cloud-Ready**:

### Вариант через Docker Compose:
```bash
docker-compose up -d --build
```
Приложение соберется в один легковесный контейнер и будет доступно на сервере по порту 8000.

### Переключение на PostgreSQL:
В файле `.env` или `docker-compose.yml` достаточно указать строку подключения:
```env
DATABASE_URL=postgresql+psycopg2://user:password@server_ip:5432/transport_db
```
SQLAlchemy автоматически создаст все таблицы и связи в PostgreSQL без необходимости менять код программы.
